# 📊 Sales Analytics Dashboard

A dynamic Excel dashboard project designed to analyze sales performance, customer behavior, product trends, and branch-wise revenue for a multinational company.

---

# 📌 Project Objective

The objective of this project is to create an interactive sales analytics dashboard using Microsoft Excel to generate meaningful business insights and support data-driven decision-making.

---

# 📂 Dataset Information

The dataset includes the following columns:

- Invoice ID
- Branch City
- Customer Type
- Gender
- Product Line
- Unit Price
- Quantity
- Total
- Date
- Payment
- Ratings

---

# 📈 Dashboard Insights

## 1️⃣ Total Sales Revenue
- Calculated total company revenue using sales data.

## 2️⃣ Monthly Sales Trends
- Visualized monthly revenue trends using charts.

## 3️⃣ Top Selling Products
- Identified top 5 products based on quantity sold.

## 4️⃣ Customer Analysis
- Analyzed customer spending patterns using bar charts.

## 5️⃣ Sales by Branch
- Compared branch-wise revenue performance using pie charts.

## 6️⃣ Sales by Customer Type
- Created pivot tables to summarize customer sales performance.
